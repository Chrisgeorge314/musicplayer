# SoundSphere 🎧

SoundSphere is an immersive, Spotify-inspired web application designed to bring music lovers closer to their favorite tracks and artists. Built as a clean, high-performance single-page application (SPA), SoundSphere combines interactive audio playback, dynamic library management, and custom playlist creation.

## 🚀 Key Features

* **Spotify-Style Interface**: A premium, dark-themed, and responsive interface optimized for desktop and mobile use.
* **Global Audio Player**: A persistent bottom dock that keeps your music playing seamlessly while you browse the site.
* **Custom Playlist Engine**: Create your own playlists, customize names, add descriptions, and upload unique cover art directly from your computer.
* **Intelligent Shuffle**: A built-in Fisher-Yates algorithm for true, randomized track playback.
* **Artist Discovery**: Explore detailed artist profiles, complete with bios, social media links, and popular release matrices.
* **User Authentication**: Secure email-and-phone-based account creation to track favorites and listening history.
* **Live Search & Filter**: Real-time filtering to find your favorite songs and artists instantly.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Storage**: LocalStorage API for persistent user data and library management.
* **Icons**: FontAwesome.
* **Architecture**: Single-Page Application (SPA) design using dynamic DOM manipulation.
